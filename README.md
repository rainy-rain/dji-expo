# 大疆出海 · 课程项目成果展（长页）

**线上地址：<https://rainy-rain.github.io/dji-expo/>**
仓库：<https://github.com/rainy-rain/dji-expo>

北京市文汇中学 七年级地理实践活动，三个小组的成果展示页。HTML + CSS 排版，`assets/js/main.js`（约 5KB，无依赖）负责滚动与指针动效；关掉 JS 页面依然完整可读。

## 怎么预览

- 直接双击 `index.html`（Chrome / Edge / Safari 均可）。
- 或者在本目录起一个本地服务：

```bash
# 任选一种
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080`。

## 动效

页面里 **208 个可见元素**都有独立的入场和出场，按类型分成四种：

| 类型 | 用在哪 | 入场 | 出场 |
| --- | --- | --- | --- |
| `rv-pop` | 数字格、卡片、时间线节点 | 上移 34px + 从 0.93 放大 | 反向缩小、下坠 |
| `rv-clip` | 标题、数字、说明文字 | 上浮 22px + 淡入 | 上移 16px 淡出 |
| `rv` | 段落、标签、表格单元格、页脚行 | 上移 52px + 淡入 | 按滚动方向反向离场 |
| `rv-mask` | 图片、视频、地图、截帧、照片 | 与底色同色的幕布向上滑走（不用 clip-path，见下） | 幕布落回覆盖 |
| `rv-left/right` | 两栏内容、两句引文 | 左右各 58px 合拢 | 原路退回 |

- **分层节奏**：先编号，再组名，再标题（第 150ms），卡片从 0 开始每张 +90ms，卡片内部标题 +80ms、正文 +150ms；表格逐行、逐格推进；页脚按标题→组员→出处→落款依次出现。所有延迟用 `--d` 控制，最长不超过 340ms。
- **出场方向**：向上滚动时元素向上收起，向下滚动时向下退场（脚本记录滚动方向），不是简单反向播放。
- **滚动**：01 的数字从 0 滚到目标值；章节大号数字随滚动反向漂移 ±46px；封面标题随滚动上移淡出。
- **指针**：封面双层柔光 + 底图/标题反向视差；深色章节与海报区光斑；卡片 ±5°、照片 ±7° 倾斜并抬起 26–34px；地图双层光斑 + 定位点错峰浮起；表格行高亮。
- **进度条**：3px 渐变，随滚动填充。
- **降级**：`prefers-reduced-motion` 下全部动效关闭、内容直接显示；打印同样强制展开；无 JS 时不会隐藏任何内容。
- **坑（已修）**：不要用 `clip-path` 给被观察的元素做入场遮罩——浏览器会把它的可见面积算成 0，IntersectionObserver 因此永远判定“没进视口”，元素将一直卡在隐藏状态（地图消失就是这样）。现在媒体元素改用一层与页面底色相同的 `::before` 幕布滑走，元素本身不裁剪。

## 素材处理记录

- **PPT 提取**：两组 PPT 里的活动照片用 python-pptx 从原始 pptx 抽出后压缩到 1400–1600px 宽。
- **视频转码**：二组视频原始文件是 HEVC（hvc1）编码，Chrome/Edge 在没装 HEVC 扩展的机器上放不出来，已用 ffmpeg 转成 H.264（`-crf 23`，1.4MB）；三组广告本来就是 H.264，未改动。
- **封面帧**：两段视频各抽一帧做 `poster`，避免加载前出现黑块。
- **地图**：底图用 Natural Earth 110m 国界数据 + 罗宾森投影重新生成 SVG（约 120KB）；六个标注点的百分比由同一套投影函数按经纬度算出（深圳 114.06E/22.54N、东京 138.2E/36.2N、美国中部 97.5W/38.8N、德国 10.3E/51.1N、巴西 52.9W/10.8S、澳大利亚中部 133.5E/25S），圆点用绝对定位锚在坐标上，不再靠目测。

## 后续可以继续打磨的点

1. 字体：现在用系统字体栈（PingFang / 微软雅黑）。想更有展陈感可换思源宋体标题或品牌字体。
2. 滚动动效：目前刻意不做淡入/视差，需要的话可加 IntersectionObserver（几行 JS）。
3. 地图：如果要更细的海岸线，可把数据换成 Natural Earth 50m（SVG 会到 400KB 左右）。
4. 移动端示意图目前横向可滚动，若嫌麻烦可做一版竖排简化图。
5. 视频体积：三组广告 4.2MB，可再压到 2MB 以内。
